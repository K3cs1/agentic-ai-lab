Agent flow

sequenceDiagram
    actor Caller
    participant Assistant as Assistant / LangChain4j
    participant Transformer as Chat request transformer
    participant MCP as MCP server
    participant Ollama as Ollama / qwen2.5

    Caller->>Assistant: answer(question)
    Assistant->>Transformer: Build request with system and user messages
    Transformer->>Transformer: Remove and retain the current user text
    Transformer->>MCP: getPrompt classify-sentiment with question text
    MCP-->>Transformer: Rendered prompt messages
    Transformer->>Transformer: Keep system message and append rendered prompt messages
    Transformer-->>Assistant: Transformed chat request
    Assistant->>Ollama: Generate answer from transformed messages
    Ollama-->>Assistant: Sentiment classification
    Assistant-->>Caller: answer
